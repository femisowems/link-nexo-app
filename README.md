# Link-Nexo

A premium, mobile-first Link-in-Bio application built with Next.js, TailwindCSS, and Framer Motion.

## Features
- 🚀 **High Performance**: Built on Next.js App Router.
- 🎨 **Premium UI**: Smooth animations and clean aesthetics.
- 📱 **Mobile First**: Optimized touch targets and layout.
- ♿ **Accessible**: WCAG 2.2 compliant (contrast, focus states, semantics).
- 🌑 **Dark Mode**: Automatic system preference support.

## Getting Started

### Prerequisites
- Node.js 18+ installed

### Installation

1.  Clone the repository (if applicable) or navigate to the project folder.
2.  Install dependencies:
    ```bash
    npm install
    ```

### Running Locally

Start the development server:
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to see the landing page.
Visit [http://localhost:3000/demo](http://localhost:3000/demo) to see the profile page example.

## Configuration

### Mock Data
Edit `src/data/mock-data.ts` to change the profile information, links, and social icons.

### Styling
Edit `src/app/globals.css` to adjust the theme variables (colors, radius).

## Deployment

This project is ready to be deployed on Vercel:
1.  Push to GitHub.
2.  Import project in Vercel.
3.  Deploy.
