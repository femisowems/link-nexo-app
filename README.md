# Link-Nexo

**Link-Nexo** is a modern, high-performance "Link in Bio" application built with Next.js 14, React, Tailwind CSS, and TypeScript. It empowers users to create a personalized, customizable profile page to showcase their links, social media presence, and content in one place.

![Link-Nexo App Preview](public/app-preview.png)

## 🚀 Features

### **Profile Management**
- **Customizable Profile Header**: Edit your name, bio, and location with inline editing.
- **Verification Badge**: Display a verified badge for trusted accounts.
- **Section Visibility**: Toggle the visibility of your profile info to customize your public view.

### **Social Links**
- **Drag-and-Drop Sorting**: Easily reorder your social icons layout.
- **Toggle Visibility**: Hide or show specific social platforms without deleting them.
- **Inline Editing**: Quickly update social URLs and platforms directly from the UI.
- **Rich Icon Library**: Supports major platforms like GitHub, Twitter/X, LinkedIn, YouTube, Instagram, Email, and generic Websites.

### **Link Management**
- **Unlimited Links**: Add as many links as you need.
- **Featured Links**: Highlight important content with special "Featured" variants and badges (e.g., "NEW", "LIVE").
- **Drag-and-Drop Reordering**: Organize your links with a smooth, accessible drag-and-drop interface.
- **Analytics Ready**: Built-in support for tracking click events on individual links.
- **Section Visibility**: Hide your entire link list with a single click while maintaining your setup.

### **Editor Experience**
- **Inline Design**: "What You See Is What You Get" (WYSIWYG) editing experience. No separate admin dashboard needed.
- **Instant Feedback**: Toast notifications for all actions (saves, reorders, deletions).
- **Optimistic UI**: Interactions feel instant with no loading states interfering with your flow.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Drag & Drop**: [dnd-kit](https://dndkit.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏃‍♂️ Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/link-nexo-app.git
    cd link-nexo-app
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to [http://localhost:3000/demo](http://localhost:3000/demo) to see the app in action.
